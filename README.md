## Requirements

- Linux (Ubuntu, CentOS, RHEL, Debian, etc.)
- Bash shell
- Root/sudo privileges for system-level operations

## Installation

```bash
git clone https://github.com/SeaDubRip/Linux-SysAdmin-Tools.git
cd Linux-SysAdmin-Tools
chmod +x *.sh
```
